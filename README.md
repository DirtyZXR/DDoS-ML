# DDoS-ML

Обнаружение DDoS-атак по признакам сетевого потока. Модель XGBoost обучается на
размеченных дампах трафика и затем классифицирует потоки в реальном времени по
четырём классам: **Syn**, **UDP**, **DrDoS_DNS** и **Benign** (легитимный трафик).

Конвейер: загрузка датасета → отсев выбросов (Isolation Forest) → стандартизация
и понижение размерности (PCA до 20 компонент) → классификатор XGBoost.

## Структура

```
DDoS-ML/
├── ddos_ml/
│   ├── features.py   # общие константы: пути к данным/моделям, список признаков, число компонент PCA
│   ├── train.py      # обучение и сохранение моделей (xgb, pca, scaler, label encoder)
│   ├── capture.py    # онлайн-захват трафика (scapy) и классификация обученной моделью
│   └── attack.py     # генератор тестового SYN-flood трафика для лаборатории
├── dataset/          # размеченные дампы трафика (*.parquet)
├── xgb_model.pkl     # обученные артефакты — готовы к использованию capture.py
├── pca_model.pkl
├── scaler.pkl
└── label_encoder.pkl
```

Датасеты и обученные модели хранятся прямо в репозитории, поэтому после клонирования
проект готов к запуску без предварительного обучения.

## Установка

```bash
python -m venv .venv
.venv\Scripts\activate      # Windows
# source .venv/bin/activate  # Linux/macOS
pip install -r requirements.txt
```

Для захвата и генерации трафика (`capture.py`, `attack.py`) нужен низкоуровневый
доступ к сети:

- **Windows** — установить [Npcap](https://npcap.com/) и запускать от администратора.
- **Linux/macOS** — запускать с правами root (`sudo`).

## Запуск

Все команды выполняются из корня репозитория.

### Обучение моделей

```bash
python -m ddos_ml.train
```

Читает датасеты из `dataset/`, обучает конвейер и перезаписывает `*.pkl` в корне.
По ходу показывает графики (накопленная дисперсия PCA, матрица ошибок).

### Онлайн-детекция

```bash
python -m ddos_ml.capture
```

Захватывает трафик активного интерфейса окнами по 5 секунд, извлекает признаки
потоков и печатает предсказанный класс для каждого потока.

### Генератор тестового трафика

```bash
python -m ddos_ml.attack 192.168.0.138 --port 80 --count 100000
```

Шлёт SYN-flood на указанную цель. Предназначен **только** для собственного
изолированного стенда (своя VM), чтобы снимать трафик атаки для обучения и проверки.
Запускать против чужих машин без разрешения недопустимо.

## Признаки

`capture.py` восстанавливает по «сырым» пакетам тот же набор из 65 признаков потока
(длительность, счётчики/размеры пакетов, межпакетные интервалы, флаги TCP и т.д.),
на котором обучены `scaler` и `PCA`. Полный список — в `ddos_ml/features.py`.
